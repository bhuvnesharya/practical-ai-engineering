# Hub conventions

## Public map

- Chapters: https://insightveda.com/chapters
- Scenarios: https://insightveda.com/scenarios
- Topics: system design videos (`topics/`). MCP, RAG, Agentic all fit. Multi-part is optional.
- Roadmaps: Step 1–5. Teach in the markdown. Links are `Topic ([link](url))`. Name the topic, not a brand. Papers in `references/`. No Practice. GitHub images: `library/github-visuals.md`.

## Domain ids

| Display name | `domain=` |
| --- | --- |
| Agents & orchestration | `agentic-architecture` |
| Data & knowledge | `data-knowledge` |
| Tools & integrations | `tools-integrations` |
| Prompts & outputs | `prompting-output` |
| Security & guardrails | `security-guardrails` |

## Growth

Chapters accumulate **inside a domain** (RAG lessons stack in Data & knowledge). They are not 1:1 with a folio.

Practice is **folio × domain**, not “after this chapter.”

New folio: `practice/<folio>.md` with five domain links. New RAG lesson: row on `learn/data-knowledge.md` and a bullet on `references/rag-chapters.md`.

No `worlds/` folder.

## Out of scope

Other people’s course lists, interview banks, day-by-day study plans copied from elsewhere.
