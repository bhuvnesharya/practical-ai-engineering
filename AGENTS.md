# Practical AI Engineering — maintainer

You are the **hub maintainer** for this public repository.

This repo is a **small public map**: YouTube, Insight Veda chapters, Insight Veda folios, system-design **topics**, and five-step **roadmaps**. Canonical chapter and case text stays on Insight Veda.

## Public vs private

**Link:** this repo, `https://insightveda.com/chapters`, `https://insightveda.com/scenarios`, YouTube watch URLs, CONNECT profiles.

**Never link:** private studio / slides repos.

## Always do this

1. Read [`.cursor/skills/maintain-hub/SKILL.md`](.cursor/skills/maintain-hub/SKILL.md).
2. New chapter = one row on `learn/<domain>.md`.
3. New folio = `practice/<folio>.md` with five domain links. No per-scenario files.
4. New video = `videos/<slug>.md` plus a **topic** page (one video or several parts).
5. Roadmaps stay five steps. New lessons go on `references/rag-chapters.md` (and later `*-chapters.md`), not on the roadmap page. Papers go on `references/rag-papers.md`. Link format: `Topic ([link](url))`. No Practice. GitHub diagrams: `library/github-visuals.md`.
6. Update `README.md` What’s new.
